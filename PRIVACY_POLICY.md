# Privacy Policy for Place ID finder

Last updated: October 14, 2026

Place ID finder reads the content of supported Search and Travel pages automatically when those supported pages load in the browser.

## What the extension does

The extension scans the current supported page to extract visible place ID values, displays the result to the user on that page, and lets the user copy the extracted value. The user can also open a place's Google reviews page by entering its place ID, and review a history of place IDs the extension has found.

## Data the extension accesses

The extension may access:

- The current page URL on supported pages
- The HTML content of the current supported page
- Place ID values found on that page
- The page title, used as the place name

## How data is used

The extension uses page content only to extract and display place IDs for the current page, and to save them to the on-device history described below.

## Data storage

The extension saves a history of up to 200 place IDs it has found. Each entry holds the place ID, the place name (taken from the page title), the type of page it was found on (Search or Travel) and when it was found. The extension also saves the user's widget settings, such as the chosen theme. This data is kept only in the browser's local extension storage on the user's device. It is never sent anywhere, and the user can erase it at any time with Clear history or by removing the extension. The extension does not store page content or browsing history.

## Data sharing

The extension does not send, sell, or share page content, place IDs, or browsing data with the developer or any third parties.

## Remote code and external services

The extension does not execute remote code and does not rely on external servers to perform place ID extraction.

## User controls

The extension runs automatically only on the supported page URLs declared in the extension manifest. It does not run on unrelated websites. Users can clear the saved history, or export it as a CSV file, from the History tab.
